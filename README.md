# Deva Gana HTML Email Suite

This repository contains a production-ready set of responsive, table-based HTML email templates built for Deva Gana LLC.

## Included templates

- `emails/welcome.html` — onboarding email for new subscribers
- `emails/abandoned-cart.html` — cart recovery email for e-commerce shoppers
- `emails/follow-up.html` — reminder email sent after cart abandonment
- `emails/receipt.html` — transactional order confirmation email
- `emails/reengagement.html` — win-back / inactive customer reactivation email
- `emails/dark-mode.html` — premium dark-mode alternate template

## Standards used

- Fully table-based layout for maximum Outlook/Gmail compatibility
- Inline CSS throughout for reliable rendering
- Mobile-friendly media query block: `@media only screen and (max-width: 600px)`
- Hidden preheader text after the opening body tag
- Explicit widths, resets, and email-safe spacing

## Notes

These templates are designed to be copy-paste ready for use in email platform builders or static hosting. Replace placeholder links and brand details as needed.
